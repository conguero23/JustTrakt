# JustTrakt 1.6.1 (Beta)

Trakt movie cards and detail pages now show watch counts as **Last seen (2)**,
removing the separate Seen N times row to save space. Counts still respect the
On Trakt watch-count setting and update when history changes.

Download **justtrakt-1.6.1.zip**, replace the installed extension files, Reload in
chrome://extensions, and refresh Trakt. The extension ID, login and settings stay
unchanged.

JustTrakt is independent and is not affiliated with JustWatch or endorsed by Trakt.
