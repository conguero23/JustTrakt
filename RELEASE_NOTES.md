# JustTrakt 1.5.2 (Beta)

A Trakt-native visual refresh:

- Charcoal surfaces, white typography and restrained orange accents; remove the green treatment from Trakt tools and filters.
- Prominent Last seen date with an uppercase label, localized formatting and orange marker.
- One full-width JustWatch action with an orange external-link indicator.
- Remove Note buttons from all movie cards and detail panels. Existing local notes are not deleted.

Posters remain clear on summary cards, with native metadata and ratings visible.
The layout was visually checked in compact and larger local card previews.

Download **justtrakt-1.5.2.zip**, replace the installed extension files, Reload in
chrome://extensions, and refresh Trakt. No new permissions, login changes or
watched-history writes. All filters and the three-year rewatch threshold remain.

JustTrakt uses Trakt but is not endorsed or certified by Trakt. Independent project,
not affiliated with JustWatch.
